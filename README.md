# ShopHub

ShopHub is the working frontend for a multi-tenant e-commerce platform.

The current runtime is Next.js App Router with React, TypeScript, Tailwind CSS,
shadcn/ui, Clerk authentication, and Drizzle/PostgreSQL wiring.

## Commands

```sh
npm run dev
npm run build
npm run lint
npm run start
```

Use `npm run build` before considering an implementation unit complete.
