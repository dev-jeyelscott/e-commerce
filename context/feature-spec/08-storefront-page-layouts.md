# Storefront Page Layouts

I want you to create a layout for storefront page layouts:

## Home

- 1st section - Carousel image with category title in the middle with a CTA button below.
- 2nd section - Display 5 tiles of featured products with 1x1 image, with product name at the bottom, price, discounted price if any, a promo banner if any, and add to cart button
- 3rd section - Display 15 tiles , 5 each row of best seller products with product name at the bottom, price, discounted price if any, a promo banner if any, and add to cart button
- 4th section - this section is for interested users who wants to sell their items in the app . you can put 4 reasons why you should sell with us , you can also use icons and a button to start selling.

## Products

- search bar
- filters
- sorting
- display 30 products , 5 each row with product name at the bottom, price, discounted price if any, a promo banner if any, and add to cart button
- pagination

## Categories

- search bar
- filters
- sorting
- display 20 categories , 4 each row with category title
- pagination

## Implementation

- use dummy data only and do not wire to any database table
- use reusable components
- product page and category page should display differently and feel differently so make sure they don't look like the same
- use shadcn ui if applicable
- use lucide icons if applicable
- use tailwind classes
- make it modern and aesthetic but professional
- use the theme preset

## Checks when done

- it uses dummy data
- uses reusable components
- product and category page feels different
- follows the theme preset perfectly
