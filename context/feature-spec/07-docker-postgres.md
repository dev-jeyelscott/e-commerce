# Docker PostgreSQL with Drizzle

I want you to wire the database to the postgres installed in the docker. database url are already in the env and ready to use.

## Implementation

- update the filename of the generated migrations and use proper naming conventions
- create a docker-compose file and connect the app
- create a database and run the migrations

## Checks when done

- the docker postgresql runs successfully without issue
- the app connects to database without issue
- generated migration should use proper naming conventions
