# Cart and Checkout Page Layouts

Create a page for Cart and Checkout

## Implementation

- Create the UI only
- use dummy data only and do not wire to any database table
- use reusable components
- use shadcn ui if applicable
- use lucide icons if applicable
- use tailwind classes
- make it modern and aesthetic but professional
- use the theme preset

### Cart

- Displays all products inside the cart
- Displays at least 20 products first and lazy load the other products as the user scrolls down
- Displays the price and discount price if any
- Displays the quantity and actions to increase/deduct quantity
- When the quantity reaches 0, a modal prompt will show to confirm deletion of product in the cart
- Displays the actual total amount and the discounted total amount if any
- Each product has a delete button icon in the top right of the row- Checkout button below to price
- Checkbox button to select what products will be checked out

### Checkout

- Displays checked out products
- Displays the price and discount price if any
- Displays the quantity and actions to increase/deduct quantity
- Displays the payment options with radio buttons to select the payment option
- Textbox to enter vouchers
- Place order button

## Checks when done

- Should be UI only
- No functionality or database wiring
- The theme is consistent
